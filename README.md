## 📌 Overview
This is a full-stack **Question & Answer forum application** built as a final project.  
Users can post questions, provide answers, and interact with a basic community-style platform.

It also includes an AI-powered RAG feature for document upload, semantic search, and question answering.

---

## ⚙️ Tech Stack

### Frontend
- React (Vite)
- JavaScript
- CSS Modules
- Axios

### Backend
- Node.js
- Express.js
- Database (MySQL or similar)

---

## 🚀 Features

- User authentication
- Post questions
- Answer questions
- View question details
- AI-powered document upload (RAG)
- Semantic search over documents
- AI question answering system

## 📂 Project Structure
frontend → React app
backend → Node.js API
